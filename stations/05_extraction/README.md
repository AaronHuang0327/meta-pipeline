# 第 05 站：資料擷取

## 這站在幹嘛

把每篇納入文獻裡「我們要的數字」抄出來，整理成一張表。
第 7 站的統計全部靠這張表——**這裡抄錯一個 SD，森林圖就是錯的**。

## 核心規則：每一格都要有出處

`extraction.csv` 的設計是：每個 outcome 的每個數值，旁邊都有一格 `source`，寫「表 2，第 5 頁」或「摘要結果段」。
這樣你核對時不用重讀全文，直接翻到那一頁對一眼。

Claude 擷取時用 `extraction_prompt.md`，它會被要求引用原文句子；**沒有出處的數字不准寫**。

## 要擷取什麼

### A. 研究特徵（每篇一列，寫在 `extraction.csv`）
作者、年份、國家、設計（RCT/世代/…）、收案期間、總樣本數、追蹤時間、資金來源

### B. 病人特徵
年齡（平均±SD）、性別比、分區/嚴重度、重要的共病

### C. 介入與對照細節
介入組做了什麼（夠細到別人能複製）、對照組做了什麼、開始時間、持續時間

### D. Outcome 數值（**每個 outcome × 每個時間點 一列**，寫在 `extraction_outcomes.csv`）
* 連續變項：各組 n、mean、SD、（原文若給 SE/CI/IQR/median 也抄，並註明）
* 二元變項：各組 n、事件數
* 原文若只給 p 值或只給圖——標記 `needs_conversion` 或 `from_figure`，並寫下你怎麼處理

## 常見的數據換算（Cochrane Handbook 6.5.2）
* SE → SD：SD = SE × √n
* 95% CI → SD：SD = √n × (upper − lower) / 3.92
* Median + IQR → mean/SD：用 Wan 2014 或 Luo 2018 公式（第 7 站腳本有）
* 多臂試驗：把相似的臂合併（Handbook 23.3.4），或只取與 PICO 最符的一臂，**要在 protocol 裡先講好**

## 步驟

1. 把 `fulltext/` 和 `extraction_template.csv` 交給 Claude，用 `extraction_prompt.md` 逐篇擷取
2. Claude 產出草稿後，你逐篇核對——**重點核對 outcome 數值與 SD**
3. 第二個人（學弟妹）再核對一次 outcome 數值。這就是「雙人獨立擷取」。
4. 不一致處回原文確認，記錄在 `extraction_log.md`
5. 需要寫信問作者的，列清單、寄信、記錄回覆

## 你要檢查什麼

- [ ] 每個數值都有 `source` 欄（頁碼/表格）
- [ ] 所有 SD 都是 SD，不是 SE 或 CI（最常抄錯的地方）
- [ ] 單位一致（度 vs 弧度；週 vs 月；0–100 vs 0–10 量表）
- [ ] 時間點對齊（6 週 vs 8 週算不算同一個時間點？protocol 要先說）
- [ ] 方向一致（分數越高越好 vs 越低越好——第 7 站要翻轉）
- [ ] 多臂試驗處理方式有記錄

## 常見踩雷

* SE 當 SD 用——效應會被高估、信賴區間過窄，審稿人一眼看出
* 不同量表的分數直接用 MD 合併（要用 SMD）
* 從圖上讀數字沒註明（可以做，但要說是用 WebPlotDigitizer 之類工具讀的）
* 同一篇兩個時間點都抄進同一列，分析時分不開
