# 第 08 站：GRADE 證據確定性

## 這站在幹嘛

第 7 站給了一個數字；這站回答「**這個數字我們敢信幾分？**」
GRADE 把答案分四級：High / Moderate / Low / Very low。每個主要 outcome 各評一次。

## 怎麼評（教學版）

起點：RCT 從 **High** 開始；觀察性研究從 **Low** 開始。
然後看五個「降級」理由，每個可以降 1 或 2 級：

| 面向 | 問自己 | 資料來源 |
|---|---|---|
| 1. 偏倚風險 | 大部分權重來自高風險研究嗎？ | 第 6 站 rob.csv |
| 2. 不一致性 | I² 高且解釋不了？各研究 CI 不重疊？點估計方向不同？ | 第 7 站 I²、森林圖 |
| 3. 間接性 | 研究的 P/I/C/O 跟我們問的一樣嗎？（例如全是 zone V，我們問 IV–VI） | 第 5 站 extraction |
| 4. 不精確 | CI 跨過「有臨床意義」與「沒意義」兩邊？總樣本數 < 400（連續）或事件數 < 300（二元）？ | 第 7 站 CI、n |
| 5. 發表偏倚 | 漏斗不對稱？小研究全是正面？大多是產業資助？ | 第 7 站 funnel、egger |

觀察性研究另有三個「升級」理由（效應很大、劑量反應、所有合理干擾都只會讓效應變小），很少用到。

## 輸出：Summary of Findings 表（`grade_sof_template.csv` → `grade_sof.csv`）

每個 outcome 一列，欄位含：研究數、參與者數、相對效應、絕對效應、確定性、降級理由。
**降級理由要寫具體**：不是「有偏倚」，是「三篇中權重 70% 的兩篇在 outcome 評估者盲化為 High」。

## 步驟

1. 把 `results/summary.txt`、`rob.csv`、`extraction.csv` 交給 Claude，要求它對每個 outcome 逐一評五個面向並給理由
2. 你逐項檢視——GRADE 有一定主觀性，**理由寫得清楚比等級本身重要**
3. 填 `grade_sof.csv`，並把這張表的文字版放進第 9 站稿件

## 你要檢查什麼

- [ ] 每個主要 outcome 都有一列
- [ ] 每次降級都有具體理由（引用哪一站的哪個數字）
- [ ] 不精確的判斷有考慮「最小臨床重要差異」（MCID），不只看 p 值
- [ ] 起點正確（RCT High / 觀察 Low）
- [ ] 沒有為了讓結論好看而手下留情

## 常見踩雷

* 每個面向都降一級，最後全部 Very low——這樣等於沒評。要有區辨力。
* 用 I² 一個數字就判不一致——篇數少時 I² 不可靠，要看森林圖 CI 重疊程度
* 忘了間接性——這是外科 SR 最常該降卻沒降的面向
