# 第 06 站：偏倚風險評讀（Risk of Bias）

## 這站在幹嘛

問每一篇納入文獻一個問題：**「這篇的結果，有多大機會是因為研究設計的瑕疵而不是真實效果？」**
這不是在批評作者，是在決定我們對合併結果能相信幾分（第 8 站 GRADE 會直接用）。

## 用哪個工具

| 研究設計 | 工具 | 面向數 |
|---|---|---|
| 隨機對照試驗 | **RoB 2**（Cochrane 2019） | 5 個 domain |
| 非隨機介入研究（前瞻/回溯世代、前後比較） | **ROBINS-I** | 7 個 domain |
| 觀察性（病例對照、世代，若 protocol 採用） | Newcastle-Ottawa Scale | 3 類 9 星 |

同一篇回顧裡可以混用（RCT 用 RoB 2，非隨機用 ROBINS-I），但要分開呈現，不要硬湊成同一張圖。

## RoB 2 五個 domain（教學版白話）

1. **隨機過程**：怎麼分組的？分組前能不能偷看？（「依住院日單雙號」就是偷看得到）
2. **偏離預定介入**：病人和治療者知不知道自己哪組？知道了有沒有換組或加治療？分析是 ITT 還是 per-protocol？
3. **缺失資料**：掉了多少人？兩組掉的比例一樣嗎？掉的人跟留的人長得一樣嗎？
4. **結果測量**：量 outcome 的人知不知道分組？（手部 ROM 由知道分組的治療師量 → 高風險）
5. **選擇性報告**：protocol 裡寫的 outcome 都報了嗎？有沒有只報好看的？

每個 domain 判 Low / Some concerns / High，最後給整體判定（任一 High → 整體 High）。

## 步驟

1. 把全文交給 Claude，要求：**每個 domain 給判定 + 理由 + 全文出處（頁碼與句子）**
   （不給出處的判定不接受——「沒寫就是沒做」是常見誤判，要分清「沒報告」與「沒做」）
2. 存成 `rob.csv`（模板見 `rob2_template.csv` / `robins_i_template.csv` / `nos_template.csv`）
3. 你獨立評一次，比對；不一致處討論後寫進 `rob_log.md`
4. 第 9 站會用 `rob.csv` 畫交通燈圖（traffic light plot）與摘要圖

## 你要檢查什麼

- [ ] 每個 domain 都有理由與頁碼
- [ ] 「未報告」與「未執行」有分開判（未報告通常是 Some concerns，不是 High）
- [ ] 主觀 outcome（疼痛、滿意度）在 domain 4 的標準比客觀 outcome 嚴
- [ ] 整體判定邏輯正確（RoB 2：任一 High → High；多個 Some concerns 也可升為 High）
- [ ] 兩位評讀者的不一致都已記錄

## 常見踩雷

* 把「單盲／雙盲」當成唯一標準——手術研究幾乎不可能盲病人，重點在 outcome 評估者有沒有盲
* 對每篇都判 Some concerns 以求安全——這樣第 8 站沒辦法降級，審稿人會覺得你沒認真看
* NOS 的星數直接當品質分數加總——NOS 沒有公認的切點，報告時要逐項呈現
