# 第 07 站：統計分析

## 這站在幹嘛

把第 5 站那張表變成一個數字（合併效應）加一張圖（森林圖），然後**誠實地說這個數字能信幾分**（異質性、敏感度、發表偏倚）。

統計本身是腳本跑的，三分鐘。真正花時間的是**事前的決定**和**事後的解讀**——這兩件事不能外包給腳本或 AI。

## 事前要決定的（protocol 裡應該已經寫了，這裡只是確認）

1. **效應量**：MD / SMD / RR / OR
2. **模型**：固定效應 vs 隨機效應
   * 白話：固定效應假設所有研究在量「同一個真實效果」，差異只是抽樣誤差；隨機效應假設每篇研究的真實效果本來就有點不同（不同醫院、不同病人、不同手法）。
   * 臨床研究幾乎都用**隨機效應**（REML 或 DerSimonian-Laird），固定效應拿來當敏感度分析。
3. **亞組**：預先設定的那幾個（例如分區、追蹤時間、研究設計）
4. **敏感度**：排除高偏倚風險研究、leave-one-out、換模型
5. **時間點**：多個時間點要分開合併，不能混

## 腳本

```bash
# 標準版（需要 R + meta + metafor）
Rscript meta_analysis.R --outcomes ../05_extraction/extraction_outcomes.csv --rob ../06_rob/rob.csv --outcome "TAM" --timepoint "12w" --measure MD --out results/

```

兩個腳本都會產出 `results/`：
* `summary.txt`：合併效應、95% CI、p、I²、τ²、Q、各研究權重
* `forest.png`、`funnel.png`
* `leave_one_out.csv`、`subgroup.csv`（若有指定）
* `egger.txt`（≥ 10 篇才有意義）

先用 `demo_data.csv` 跑一遍熟悉輸出長什麼樣子。

## 讀結果的方法（教學重點）

### 合併效應
看點估計 + 95% CI。**CI 跨不跨 0（MD/SMD）或 1（RR/OR）**是統計顯著；但更重要的是 **CI 的寬度跟臨床意義的關係**——MD = 5 度 ROM，CI 2–8，統計顯著但臨床上有差嗎？這段話只有你能寫。

### 異質性
* I² 是「變異中有多少比例不是抽樣誤差」。粗略：< 40% 可忽略；40–60% 中等；> 60% 要解釋。
* **I² 高不是分析失敗，是線索。** 去亞組和敏感度分析找原因（是某一篇在拉？是設計不同？是量表不同？）。
* τ² 是真實效果的變異數，比 I² 更能反映絕對異質程度。

### 發表偏倚
* 漏斗圖不對稱 + Egger p < 0.1 → 可能有小研究效應（small-study effect），其中一種原因是發表偏倚。
* **< 10 篇時檢定沒有檢力**，不要硬做結論；可以畫圖但要註明。
* 不對稱也可能是真實異質性或方法品質差異，不要直接說「有發表偏倚」。

### 敏感度
leave-one-out 時如果拿掉某一篇結論就翻轉，那篇要特別討論（通常是樣本最大或偏倚最高的那篇）。

## 你要檢查什麼

- [ ] 輸入的 SD 已全部換算成真正的 SD（腳本會對 reported_as ≠ mean_sd 的列發出警告）
- [ ] 方向已統一（higher_is_better 欄；腳本會對 no 的列乘 −1）
- [ ] 模型與亞組跟 protocol 一致；若不一致，在 `results/deviations.md` 說明理由
- [ ] 森林圖上每篇研究的數字跟 extraction 表對得上（抽查三篇）
- [ ] 森林圖排序合理（依年份或依權重）
- [ ] 有寫 `results/interpretation.md`：三段話——效應、異質性、可信度

## 常見踩雷

* 一個研究兩個時間點都放進同一個森林圖——同一群病人算兩次
* 多臂試驗對照組重複使用——要分割對照組 n
* I² = 0% 就說「無異質性」——篇數少時 I² 沒有檢力
* 用固定效應得到顯著、隨機效應不顯著，然後只報固定效應——這叫 p-hacking
