Systematic Review & Meta-Analysis · 九站閘門生產線

Meta 生產線手冊

把一篇統合分析拆成九個工作站。AI 做苦工，人做判斷；每站做完要蓋章，沒蓋章下一站不開工。照著走一遍，你就學會了整個 SR/MA；下一個題目，再走一遍就好。

已蓋章 0 / 9 · 蓋章紀錄只存在你這台瀏覽器，正式紀錄在 manifest.json

先讀這個：閘門的三條規矩

不跳站

第 N 站的章，要第 N−1 站先蓋好。gate.py 會擋，不是建議，是強制。

每個判斷附出處

篩選附理由、擷取附頁碼、評讀附句子。沒出處的數字不准進檔案——未來的審稿人跟未來的你都會感謝。

上游改了，下游重跑

gate.py reopen 會把那一站之後全部打回。簽核後偷改檔案，status 會標 ⚠ 要求重簽。這不是懲罰，是誠實。

AI 不是審查者

篩選與資格判定由第一、第二作者各自看完每一筆；LLM 只做預篩排序與品管旗標。投稿時 Methods 才寫得出來。

每一步自動留痕

每支腳本跑完都把「誰、何時、哪支腳本、參數、產出檔與 sha256、幾列」寫進 manifest.json。gate.py events 題目 就是你的審計軌跡，可當補充資料附在稿件後。手動做的事用 gate.py log 補記。

一篇接一篇：看板

gate.py board 列出所有題目與各自的下一站。跟 Claude 說「繼續」，它會挑第一個輪到它做的站做完、停下；全部在等人簽核時，它列出每題在等誰。多條線同時走，你只需要蓋章。

整條線的實體是 meta-pipeline/ 資料夾：stations/ 放九站的模板與腳本，projects/<題目>/ 是每個題目自己的工作區，manifest.json 記錄誰、何時、為什麼蓋了章。開新題目：python gate.py new 題目名。

九站全部通過 🌞
投稿去吧。然後把下一個題目丟進同一條線。

跟 Claude 一起跑：把 meta-pipeline/ 整個交給 Claude，說「依 SKILL.md 從第 N 站開始」。SKILL.md 規定它每站結束必須停下來等你蓋章。

投稿時要寫的兩句話：「Two reviewers independently screened all records; disagreements were resolved by a third reviewer. A large language model (Claude, Anthropic) was used to pre-screen and prioritise records and to flag potential false exclusions for re-examination; it did not replace either human reviewer.」

留痕在哪：每個題目的 manifest.json。gate.py events 題目 列出全部事件；gate.py board 看所有題目走到哪。

方法學依據：Cochrane Handbook 6.x、PRISMA 2020、RoB 2 / ROBINS-I、GRADE。
